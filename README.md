# Creative Solutions FTech

Este projeto é uma página web estática que apresenta a empresa fictícia **Creative Solutions FTech** e seus serviços em tecnologia para o varejo.

## Descrição do projeto

A proposta é criar um site institucional de apresentação para uma empresa de soluções comerciais, com foco em:

- Visão geral da empresa
- Serviços oferecidos (sistemas PDV, controle de estoque, gestão de vendas, integração com TEF e maquininhas)
- Projetos e portfólio visual
- Parcerias com marcas conhecidas
- Seção de FAQ para esclarecer dúvidas comuns

O layout inclui um menu lateral fixo, seções principais no conteúdo central, cards informativos e um slideshow de imagens de exemplo.

## Tecnologias aplicadas

- `HTML` para a estrutura da página
- `CSS` customizado em `styles.css` para aparência, layout responsivo e efeitos visuais
- `JavaScript` leve em `assets/script.js` para controlar o slideshow de imagens
- `W3.CSS` (via CDN) para classes utilitárias e componentes básicos de layout
- `Font Awesome` (via CDN) para ícones nos botões de navegação do slideshow

## Arquivos principais

- `index.html`: página principal do site
- `styles.css`: estilos personalizados e layout
- `assets/script.js`: comportamento do slideshow
- `assets/img/`: imagens usadas no conteúdo do site

## Como usar

Basta abrir o arquivo `index.html` em um navegador para visualizar o site.

> Observação: as dependências externas (`W3.CSS` e `Font Awesome`) são carregadas via CDN, portanto é necessário conexão com a internet para que esses recursos sejam exibidos corretamente.
